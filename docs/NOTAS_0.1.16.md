# Senderos del Horizonte 0.1.16

- Las cortezas con albedos opacos usan un shader sin el recorte de hojas.
  Se mantienen las transparencias de las hojas y las texturas originales.
- Conserva geometría, hierba, distancia visual, sombras, tintes y viento.
- Pruebas de opacidad, caché, recarga y conservación de recursos; controles
  visuales de día, noche y tormenta y cooperación con dos procesos reales.

En el M2 Pro, el recorrido definitivo mejora aproximadamente **3,2–3,5 %**
en las vistas del bosque verde. Puerto mejora un 2,8 % de media, con un p95
peor; el Tenebroso apenas varía. El objetivo general de 100–120 FPS sigue
pendiente.

[Mediciones y comprobaciones](https://github.com/Francisco44444/godot_beautiful_space/blob/v0.1.16/docs/OPACIDAD_DE_LA_CORTEZA.md).
El ZIP completo con el .exe continúa como descarga principal de la web;
el instalador permanece como alternativa.
