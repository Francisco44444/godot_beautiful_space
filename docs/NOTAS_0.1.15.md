# Senderos del Horizonte 0.1.15

- Las grutas conservan su colisión cuando un invitado está dentro y el
  anfitrión permanece lejos.
- Las flechas del invitado pueden recorrer el interior y alcanzar objetivos;
  la protección del terreno distingue la bóveda física de la tierra maciza.
- Las luces siguen al héroe y a la cámara local, sin encender grutas por
  invitados lejanos. Se apagan al abandonar la zona.
- Pruebas de las cuatro grutas y cuatro impactos con el arco real entre dos
  procesos ENet, además del combate, tala y restauración anteriores.

El barrido de las cuatro grutas cuesta unos **0,013 ms** con ocho jugadores
simulados y se realiza cada 350 ms. Los FPS gráficos se mantienen; no cambia
la calidad visual ni se alcanza todavía el objetivo general de 100–120 FPS.

[Mediciones y límites](https://github.com/Francisco44444/godot_beautiful_space/blob/v0.1.15/docs/GRUTAS_EN_COOPERATIVO.md).
La web mantiene el ZIP completo con el .exe como descarga principal y el
instalador como alternativa.
