# Senderos del Horizonte 0.1.19

- En cooperativo, leer una memoria o abrir el inventario, el diario y los menús
  mantiene activa la expedición. La pausa individual se conserva.
- Las ventanas bloquean los controles locales del héroe, el caballo y la
  cámara; cerrar una respeta las demás que sigan abiertas.
- Abrir una ventana cancela el arco y la carga; el clic de cierre no ataca.
  El atajo H deja de llamar al caballo desde el inventario.
- Comprobaciones con dos procesos ENet, cliente Metal, capturas y 22 defectos
  inyectados con restauración de las fuentes.

[Comprobaciones, coste y límites](https://github.com/Francisco44444/godot_beautiful_space/blob/v0.1.19/docs/PAUSA_EN_COOPERATIVO.md).
El objetivo general de 100–120 FPS sigue pendiente. El ZIP completo con el
.exe continúa como descarga principal; el instalador queda como alternativa.
