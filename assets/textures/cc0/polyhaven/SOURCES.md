# Poly Haven CC0 materials

All files in this directory are the 1K JPG variants of Poly Haven materials,
licensed under Creative Commons CC0 1.0 Universal.

- `forest_ground_03`: https://polyhaven.com/a/forrest_ground_03 — Rob Tuytel.
- `mossy_cobblestone`: https://polyhaven.com/a/mossy_cobblestone — Sơn Nguyễn.
- `mossy_rock`: https://polyhaven.com/a/mossy_rock — Rob Tuytel.

For each material the project includes diffuse, OpenGL normal and roughness.
`normal_roughness.png` is a derived packing for Godot (normal RGB, roughness A).
